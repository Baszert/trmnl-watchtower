# Watchtower Plugin

An artistic generative plugin for TRMNL that creates a unique watchtower scene every time it refreshes, giving you the feeling of looking out from a watchtower.

## Overview

This plugin generates procedural artwork that simulates the view from a watchtower. Each refresh creates a new, unique scene with different elements. Choose from three distinct visual themes to match your aesthetic preference.

## Features

- **Procedurally generated scenes** - Every refresh creates a unique view
- **Three visual themes** - Terrain, Moon, or Original color schemes
- **Artistic display** - Minimalist, contemplative aesthetic
- **Daily refresh** - New scene every 24 hours
- **No configuration needed** - Just pick your theme and enjoy

## Settings

### What do you want to look out on?
- **Type:** Dropdown
- **Description:** Choose your preferred scene theme
- **Options:**
  - **Terrain** - Grey colorscheme optimized for TRMNL's e-ink display
  - **Moon** - See the moon and stars in the background
  - **The Original** - The original idea with full colors
- **Default:** Terrain

## Theme Details

### Terrain
The terrain theme uses a grey colorscheme that's specifically optimized for TRMNL's e-ink display. This theme provides excellent contrast and clarity, making it perfect for the device's screen technology. The scenes feature landscapes and natural elements in monochromatic tones.

### Moon
Look up at the night sky! This theme features the moon and stars in the background, creating a peaceful, contemplative nighttime scene. Perfect for those who enjoy stargazing and celestial views.

### The Original
This is the original concept with full color implementation. It features the complete color palette as originally envisioned by the creator, offering a more vibrant and colorful watchtower experience.

## Technical Details

- **Strategy:** Static
- **Refresh Interval:** 1440 minutes (24 hours)
- **Screen Padding:** Yes
- **Dark Mode Support:** No
- **Category:** Art

## How It Works

The plugin uses procedural generation techniques to create unique watchtower scenes. Each time the display refreshes (every 24 hours), a new random scene is generated based on your selected theme. No two views are exactly alike, providing an ever-changing artistic display.

## Layout Support

This plugin supports all TRMNL layout sizes:
- Full screen (recommended for maximum artistic impact)
- Half horizontal
- Half vertical
- Quadrant
