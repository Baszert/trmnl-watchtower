# Watchtower

Like looking out of a watchtower: a freshly generated landscape on every refresh.

<a href="https://trmnl.com/recipes/189444"><img width="150" alt="Works with TRMNL" src="https://trmnl.com/images/brand/badges/light/works-with-trmnl/trmnl-badge-works-with-light.svg" /></a>

## Settings
- **Theme:** Terrain (grayscale, made for TRMNL), Moon (moon and stars) or The Original (with colors)

Generator idea by [Kevin Wang](https://kwa.ng). Watchtower icon by Herra Studio (Noun Project).

### Develop locally

Templates and settings live in [`src/`](src/), ready for [trmnlp](https://github.com/usetrmnl/trmnlp):

```sh
gem install trmnl_preview
trmnlp serve
```
